# TheUndercutProject

Formula E race-engineering notes, extracted from OneNote into Markdown so they
can be searched, queried and reasoned over across seasons.

## Layout

| Path                | What it is                                                     |
| ------------------- | -------------------------------------------------------------- |
| `notes/`            | Exported pages, one Markdown file per OneNote page. Generated — do not hand-edit. |
| `notes/.manifest.json` | Per-page export state for incremental sync.                 |
| `docs/inventory.json` | Notebook/section/page counts from the last `--inventory` run. |
| `tools/`            | The exporter. See `docs/EXTRACTION.md`.                        |

`notes/` is regenerated by `tools/onenote_export.py` and an export overwrites
it. Derived or hand-curated data belongs in a separate tree (`data/`), never
inside `notes/`.

## Working with the notes

- Front matter schema and the section naming convention: `docs/SCHEMA.md`.
- Pages with handwriting are flagged `has_ink: true`; their ink is only present
  as images in `assets/`, never as text. Do not assume such a page's Markdown is
  complete.
- Page ordering within a section is encoded in the `NNN-` filename prefix.
- Reading order inside a page is reconstructed from canvas coordinates and is
  usually but not always right — see the note in `docs/EXTRACTION.md`.

## Domain glossary

Drawn from the notebooks themselves. **The entries marked (?) are guesses from
context and need confirming** — correct them in place rather than leaving them
ambiguous, since downstream parsing will lean on this table.

| Term | Meaning |
| ---- | ------- |
| `FE` | Formula E |
| `Gen3` | Third-generation Formula E chassis (Spark Racing Technology) |
| `S09`, `S10`, `S11` | Championship season number |
| `CEng` | Chief Engineer |
| `DiL` | Driver-in-the-Loop (simulator session) |
| `KC` | (?) recurs as `KC Notes`, `KC13 Notes`, `[Driving_KC]` |
| `EMS` | (?) Energy Management Strategy — appears as `Day1 - EMS Notes` |
| `ORH` | (?) named alongside Outlook/Teams/Planner as a tool on the engineering screens |
| `FCY` | Full Course Yellow |
| `RESS` | Rechargeable Energy Storage System (the battery) |
| `BBW` | Brake-By-Wire |
| `MFE` | (?) appears as `Alpine MFE` |
| `PWT` | (?) Powertrain |
| `TN` | Technical Note — numbered bulletins from Spark Racing Technology |
| `ATLAS` | McLaren Applied telemetry analysis software |
| `derating` | Power limit imposed by the battery, e.g. "RESS derating (250kW)" |
| `torque map` | Mapping of driver demand to motor torque |
| `powercut` | Loss of drive, often logged consecutively as a fault |

### Driver codes

Three-letter abbreviations seen in the notes: `HUG`, `BIR`, `ROW`, `FEN`,
`RAS`. Expand as more appear.

### Venue and facility codes

Trailing token of a section name. Seen so far: `SAO` (São Paulo), `MIS`
(Misano), `SHA` (Shanghai), `DRH` (Diriyah), `VLC` (Valencia), `RME` (Rome),
`CAL` (Calafat), plus the dyno facilities `CRITT` and `KIN`.

## Conventions

- Python: standard library plus the pinned deps in `requirements.txt`. No
  framework.
- Never commit tokens. Auth state lives in `~/.cache/undercut/`.
- The notes contain internal team engineering data. Treat the contents as
  confidential — do not paste page content into external services.
